Sauvegarde de la base

                

              

              
Créez une sauvegarde complète SQLite de la base locale (format recommandé pour une restauration ISO).

              

                Astuce
                
Conservez une copie par date dans un dossier de sauvegarde dédié.

              

              

                
              

            


            

              

                

                  
Import d'une base

                

              

              
Importez un fichier SQLite pour remplacer la base locale actuelle.

              

                Attention
                
L'import remplace l'état courant du poste. Vérifiez le fichier avant confirmation.

              

              

                
              

            


            

              

                
Règles de gestion

              

              
    
                
  • La sauvegarde SQLite contient l'ensemble des tables (compétitions, juges, notes, accès, grilles...).
    • 
                
  • L'import restaure un état complet de base sur le poste local.
    • 
                
              

              

                Réseau local
                
Le filtrage MAC reste géré par le routeur dédié. L'interface met en avant les adresses LAN disponibles pour les tablettes.
